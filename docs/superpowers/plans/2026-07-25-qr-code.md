# QR Kod Ekleme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kartvizit-react.html`'e, kartın canlı deploy edilmiş URL'ine işaret eden bir QR kod eklemek (`qrcode.react` kütüphanesi ile), kartın içinde iletişim listesinin altında.

**Architecture:** Mevcut Babel/UMD React ağacına dokunulmaz. QR kod, `esm.sh` üzerinden native ES module olarak import edilen `react`/`react-dom/client`/`qrcode.react` ile **ayrı, bağımsız bir React root**'unda (`#qr-code` div'i) render edilir — bu, iki farklı React kopyası arasında hook çakışmasını (`Invalid hook call`) engeller. Detaylar için bkz. `docs/superpowers/specs/2026-07-25-qr-code-design.md`.

**Tech Stack:** Vanilla HTML/CSS, React 18 (mevcut UMD + yeni ESM), Babel Standalone (mevcut, değişmez), `qrcode.react` (esm.sh CDN, npm kurulumu yok), GitHub CLI (`gh`) + GitHub Pages.

## Global Constraints

- Proje genelinde npm install / build adımı yok (bkz. `.claude/skills/bizcard-conventions/SKILL.md`) — bu özellik de bu kısıtı korur, tüm yeni bağımlılıklar CDN üzerinden (esm.sh) yüklenir.
- Tüm değişiklikler tek dosyada (`kartvizit-react.html`) kalır — ayrı bileşen dosyası oluşturulmaz.
- QR kod rengi varsayılan siyah/beyaz kalır (taranabilirlik için), boyut 140px.
- Canlı URL: `https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html` (GitHub Pages, `main` dalı, kök dizin `/`).
- Bu özellik için otomatik test yazılmaz (spec'te belirtildiği gibi saf mantık içermiyor) — doğrulama manuel/curl ile yapılır.

### Task 2: QR Kodu `kartvizit-react.html`'e Entegre Et

**Files:**
- Modify: `kartvizit-react.html`

**Interfaces:**
- Consumes: Task 1'de doğrulanan canlı URL (`https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html`).

- [ ] **Step 1: `.qr-code` stilini `<style>` bloğuna ekle**

`kartvizit-react.html` içinde `@media (max-width: 420px) { ... }` bloğundan hemen sonra, `</style>` etiketinden hemen önce ekle:

```css
  .qr-code {
    margin-top: 20px;
    display: flex;
    justify-content: center;
  }
```

- [ ] **Step 2: Boş QR container'ı `ProfileCard` bileşenine ekle**

`kartvizit-react.html` içindeki `ProfileCard` fonksiyonunu bul:

```jsx
    function ProfileCard({ name, title, initials, contacts }) {
      return (
        <div className="card">
          <Avatar initials={initials} />
          <h1 className="name">{name}</h1>
          <p className="title">{title}</p>
          <hr className="divider" />
          <ContactList items={contacts} />
        </div>
      );
    }
```

`<ContactList items={contacts} />` satırının hemen altına ekle (kartın kapanış `</div>`'inden önce):

```jsx
    function ProfileCard({ name, title, initials, contacts }) {
      return (
        <div className="card">
          <Avatar initials={initials} />
          <h1 className="name">{name}</h1>
          <p className="title">{title}</p>
          <hr className="divider" />
          <ContactList items={contacts} />
          <div id="qr-code" className="qr-code"></div>
        </div>
      );
    }
```

- [ ] **Step 3: QR render script'ini ekle**

`kartvizit-react.html` içinde mevcut `<script type="text/babel">...</script>` bloğunun kapanışından hemen sonra, `</body>` etiketinden önce ekle:

```html
  <script type="module">
    import React from "https://esm.sh/react@18";
    import { createRoot } from "https://esm.sh/react-dom@18/client";
    import { QRCodeSVG } from "https://esm.sh/qrcode.react@3";

    const CARD_URL = "https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html";

    createRoot(document.getElementById("qr-code")).render(
      React.createElement(QRCodeSVG, { value: CARD_URL, size: 140 })
    );
  </script>
```

- [ ] **Step 4: Yerelde tarayıcıda doğrula**

Run: `open kartvizit-react.html`
Expected: Kart normal şekilde görünür (avatar, ad, ünvan, iletişim listesi), iletişim listesinin altında 140px'lik bir QR kod belirir. Tarayıcı konsolunda (DevTools) hata olmamalı. QR kodu bir telefon kamerasıyla tarayınca `https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html` adresine yönlendirmeli.

- [ ] **Step 5: Commit**

```bash
git add kartvizit-react.html
git commit -m "feat: add QR code linking to live card URL"
```

- [ ] **Step 6: Push ve canlı deploy'u doğrula**

Run:
```bash
export PATH="$HOME/.local/bin:$PATH"
git push
sleep 60
curl -s https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html | grep -o 'id="qr-code"'
```
Expected: `id="qr-code"` çıktısı görünür (GitHub Pages'in güncel dosyayı yayınladığının kanıtı). Görünmezse 30 saniye daha bekleyip tekrar dene.

- [ ] **Step 7: Canlı URL'de son manuel doğrulama**

Run: `open https://metinazeri.github.io/bizcard-miuul/kartvizit-react.html`
Expected: Adım 4'teki aynı görsel sonuç, artık canlı URL üzerinden. QR kodu telefonla tarayıp aynı sayfayı açtığını doğrula.
